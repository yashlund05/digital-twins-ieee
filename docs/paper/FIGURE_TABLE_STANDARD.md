## 2. Typography and Visual Style

### Font Rules
- **Family:** Helvetica, Arial, or Times New Roman (must match the document body font).
- **Size Scale:**
  - Axis labels: 8 pt to 10 pt
  - Tick labels: 7 pt to 8 pt
  - Legends: 7 pt to 8 pt
  - In-plot annotations: 7 pt
- *Constraint:* Never produce text smaller than 6 pt when the figure is scaled to its final column width.

### Color and Contrast
- **Colorblind Safe:** Use colorblind-accessible palettes:
  - Categorical comparisons: Seaborn `colorblind`, Okabe-Ito palette, or Tableau 10.
  - Continuous/Heatmap gradients: `viridis`, `plasma`, or `cividis`. Never use rainbow / jet.
- **Grayscale Legibility:** All line plots must remain distinguishable when printed in black-and-white. Use distinct line markers (`o`, `s`, `^`, `D`, `v`) and distinct line styles (`-`, `--`, `-.`, `:`).
- **Line Widths:** Primary curve lines: 1.25 to 1.75 pt; grid lines: 0.5 pt (dashed, alpha = 0.4); axes/spines: 0.75 pt.

## 3. Output File Formats

Every figure generation script must save dual outputs to `artifacts/figures/`:
1. **Vector PDF (`.pdf`):** Primary format embedded in the LaTeX manuscript. Fonts must be embedded (TrueType/Type 1).
2. **High-Resolution PNG (`.png`):** 300 to 600 DPI raster version for fast markdown viewing and presentations.

```python
# Standard matplotlib export snippet in src/visualization/
plt.savefig(output_path.with_suffix(".pdf"), bbox_inches="tight", dpi=300)
plt.savefig(output_path.with_suffix(".png"), bbox_inches="tight", dpi=300)
```
